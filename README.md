## Vybrané projekty

### [Osobní web](https://github.com/StanekRoman/osobni-web)

Kompletní redesign a migrace osobního webu z WordPressu na Next.js.

Projekt zahrnuje návrh komponentové architektury, responzivní rozhraní, dynamické stránky služeb, serverové API pro poptávkový formulář, integraci e-mailové služby a SEO migraci.

**Stack:** Next.js 16, React 19, TypeScript, Chakra UI v3, Zod, Resend, Vercel.
